\# Atividade Prática 07 - Python (Escola da Nuvem)



Este repositório contém scripts Python desenvolvidos como parte da Atividade Prática 07, relacionados à manipulação de arquivos CSV e JSON, além da realização de cálculos estatísticos com dados provenientes de logs de treinamento de modelos de Machine Learning.



---



\## 📚 Atividades



\### 📝 Atividade 1 - Estatísticas de Logs



\*\*Objetivo:\*\*

Ler um arquivo CSV contendo logs de treinamento de modelos de Machine Learning, calcular e exibir a média e o desvio padrão dos tempos de execução.



\*\*Formato do CSV:\*\*



```csv

modelo,tempo\_execucao

ModeloA,120

ModeloB,150

ModeloC,130

ModeloD,110

ModeloE,140

```



\### 📂 Atividade 2 - Escrita em CSV



\*\*Objetivo:\*\*

Criar um script Python que escreva informações de pessoas em um arquivo CSV, com as colunas \*\*Nome\*\*, \*\*Idade\*\* e \*\*Cidade\*\*.



\*\*Exemplo de CSV gerado:\*\*



```csv

Nome,Idade,Cidade

Alice,30,Salvador

Bruno,25,Fortaleza

Carla,28,Belo Horizonte

```



\### 📖 Atividade 3 - Leitura de CSV



\*\*Objetivo:\*\*

Criar um script Python que leia um arquivo CSV contendo informações de pessoas (Nome, Idade, Cidade) e exiba esses dados no terminal.



\### 📄 Atividade 4 - Manipulação JSON



\*\*Objetivo:\*\*

Criar um script Python capaz de escrever e ler dados em formato JSON, contendo informações sobre uma pessoa, com campos \*\*nome\*\*, \*\*idade\*\* e \*\*cidade\*\*.



\*\*Exemplo de JSON:\*\*



```json

{

&nbsp;   "nome": "Maria",

&nbsp;   "idade": 32,

&nbsp;   "cidade": "Rio de Janeiro"

}

```

\## 🚀 Como Executar



Cada atividade está organizada em scripts individuais. Para executar, siga os passos abaixo:



\### Clonar repositório:



```bash

git clone https://github.com/seu-usuario/Atividade-Pratica-07.git

cd Atividade-Pratica-07

```



\### Executar scripts:



\* \*\*Atividade 1:\*\*



```bash

python atividade1\_estatisticas\_logs.py

```



\* \*\*Atividade 2:\*\*



```bash

python atividade2\_escrever\_csv.py

```



\* \*\*Atividade 3:\*\*



```bash

python atividade3\_ler\_csv.py

```



\* \*\*Atividade 4:\*\*



```bash

python atividade4\_json.py

```
